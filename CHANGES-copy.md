- Arabic addresses the reader in the feminine everywhere: شاهدي، تسوقي الآن، تواصلي معنا، أرسلي، ماذا تشاهدين؟، لاحظي (buttons, headings, footer, contact, meta).

- "Culotte" and "(سروال)" removed; formats are Tape diapers / Pants · حفاض بلاصق / كلوت.
- Language switch shows "English" / "العربية" (pill instead of code circle).
